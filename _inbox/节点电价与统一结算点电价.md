## 1. 基本关系

节点电价是反映电力在**具体电网节点、具体时段**的边际价值，体现的是电价的**空间差异**。它通常受系统供需、机组报价、输电阻塞、网损、局部负荷、新能源出力等因素影响。

统一结算点电价不是某一个物理节点的价格，而是市场为了结算方便，将**多个节点电价按照一定规则汇总形成的代表性价格**。

$$
USP_h = \sum_n w_{n,h} * LMP_{n,h}
$$

$$
LMP_{n,h} = \lambda_h + Loss_{n,h} + Congestion_{n,h}
$$

可以简化理解为：
```
各节点电价 → 按规则加权汇总 → 统一结算点电价
```

常见表达式为：
```
统一结算点电价 = Σ(节点电价 × 节点权重)
```

因此：
- 节点电价反映“不同位置的真实边际电价”。
- 统一结算点电价反映“市场统一用于结算的代表价格”。
- 当电网无明显阻塞、网损差异较小时，各节点电价接近，统一结算点电价也接近各节点价格。
- 当电网阻塞明显、局部供需紧张时，节点电价会出现分化，统一结算点电价只能代表加权平均水平，不能完全反映每个节点的真实价格。
## 2. 节点电价的形成因素

节点电价一般可以理解为由三部分组成：
```
节点电价 = 系统能量价格 + 阻塞价格 + 网损价格
```

其中：
- 系统能量价格：反映全系统电力供需平衡下的边际发电成本。
- 阻塞价格：反映输电通道受限、局部供需不平衡带来的价格差异。
- 网损价格：反映电力从发电侧输送到负荷侧过程中产生的损耗成本。

结合电价分析逻辑，节点电价受两类因素共同影响：
- 出清量相关因素：省调负荷、申报量、检修阻塞、时间结构、装机量、空间位置等。
- 出清价相关因素：一次能源价格、机组申报价格、主观报价因素、政策和库存等。

这些因素共同影响市场出清结果，进而形成不同节点的节点电价。

## 3. 统一结算点电价的权重如何确定

统一结算点电价的关键在于“权重”。权重通常由市场规则确定，本质是看某个节点在统一结算价格中代表了多少电量。

常见权重计算方式为：
```
节点权重 = 该节点对应结算电量 / 所有参与节点结算电量总和
```

例如：

|节点|节点电价|结算电量|权重|
|---|---|---|---|
|A|300元/MWh|100MWh|20%|
|B|400元/MWh|300MWh|60%|
|C|500元/MWh|100MWh|20%|

则统一结算点电价为：
```
300 × 20% + 400 × 60% + 500 × 20% = 400元/MWh
```

## 4. 常见权重口径

不同市场、不同结算场景下，权重口径可能不同。

### 按负荷电量加权
以各节点或分区的用户侧用电量作为权重。  
这种方式常用于==用户侧==统一结算价格。用电量越大的节点，对统一结算点电价影响越大。

### 按发电上网电量加权
以各发电节点的实际上网电量或出清电量作为权重。  
这种方式更偏向==发电侧==价格统计或发电侧结算。

### 按市场出清电量加权
以日前、实时市场中各节点实际出清电量作为权重。  
这种方式更贴近市场真实运行结果。

### 按分区电量加权
部分市场不会直接对所有节点逐一加权，而是先形成分区价格，再按照分区电量汇总形成统一结算点电价。

## 5. 一句话总结
节点电价反映空间位置上的真实边际电价，统一结算点电价是多个节点电价按结算规则加权形成的代表性价格。节点电价体现“哪里贵、哪里便宜”，权重体现“哪个节点代表的电量更重要”，统一结算点电价则体现“市场最终拿哪个代表价格来结算”。
