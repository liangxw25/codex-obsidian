## 5. Cross-cutting findings

### 5.1 Path traversal posture：STRONG

`test_wiki_mode.py` 通过 `os.path.abspath()` 验证：

- `../../../etc/passwd`
- `/etc/passwd`
- Windows 风格 `..\\..\\`
- `\x00` 注入

都留在 vault 内。

两层 sanitization：

1. `scripts/wiki-mode.py` 的 `slugify()` + `safe_name()`；
2. `scripts/wiki-lock.sh` 的 `validate_path()`。

LOW 风险点：`contextual-prefix.py collect_pages()` 对 CLI target 的 resolve / relative-to 检查可进一步 harden。

### 5.2 `allowed-tools` frontmatter：有缺口

多个 skills body 会调用 bash/python，但 frontmatter 未授予 `Bash` 或缺 `allowed-tools`。历史上 skills 可工作，说明 harness 可能默认允许；但 agents 更严格，因此 `agents/wiki-ingest.md` 被提升为 H2。

### 5.3 Hook safety：PASS

- SessionStart：只读 `wiki/hot.md`；
- PostCompact：提示重读 hot；
- PostToolUse：lock check 后 auto-commit，无 shell injection；
- Stop：有一个 LOW 功能问题，若 PostToolUse 已 commit，diff 为空会跳过提醒。

### 5.4 Plugin manifest accuracy：PASS

plugin / marketplace version、CHANGELOG、install command 与 source repo 匹配（在上游历史语境中）。

### 5.5 Verifier dispatch

staged v1.8.2 diff：`CLEAR TO COMMIT`。

- 0 BLOCKER
- 0 HIGH
- 1 MEDIUM
- 4 LOW
