## 2 个 BLOCKER

### B1 — Auto-commit hook blast radius（Data）

**文件：** `hooks/hooks.json` PostToolUse

**问题：** 当 `wiki-lock list` 非空时，hook 推迟 `git commit`。下一次 PostToolUse 没有锁时，hook 执行 `git add wiki/ .raw/ .vault-meta/` + `git commit`，但会把用户已 staged 的无关文件一起提交到 `wiki: auto-commit` 下。

复现：

```bash
echo unrelated > TEST.md && git add TEST.md
# 之后执行任何 wiki/ Write，hook 会把 TEST.md 卷入 auto-commit
git log -1 --stat
```

修复方案：

- 用明确 pathspec 的 `git add -- wiki/ .raw/ .vault-meta/` 和 `git commit -- wiki/ .raw/ .vault-meta/`；
- 或 hook 入口发现已有 staged changes 时跳过 auto-commit。

### B2 — Chunk write 非原子（Data）

**文件：** `scripts/contextual-prefix.py:376`

**问题：** `chunk_path.write_text(...)` 直接写入。崩溃、SIGKILL、ENOSPC 中断时会留下半写 `chunk-NNN.json`。`discover_chunks()` 捕获 `JSONDecodeError` 后静默跳过，导致该 chunk 从 BM25 + embed index 中消失，直到重新 ingest。

复现：

```bash
python3 scripts/contextual-prefix.py --build &
PID=$!
sleep 2 && kill -9 $PID
find .vault-meta/chunks -name 'chunk-*.json' -exec sh -c \
  'python3 -c "import json,sys; json.load(open(sys.argv[1]))" "$1" 2>/dev/null || echo "CORRUPT: $1"' _ {} \;
```

修复：采用 `tmp.write_text(); os.replace(tmp, chunk_path)`，复用 `bm25-index.py` 中已有模式。

## 12 个 HIGH

### Data（4 个）

- **H1**：`git add wiki/ .raw/ .vault-meta/` 缺 `--` 分隔符；`wiki/-flag.md` 可能被当作 flag。修：`git add -- ...`。
- **H2**：`wiki-lock.sh release` 是无条件 `rm -f`，任意进程可释放任意锁。单租户设计可接受，但应在 SECURITY.md 说明。
- **H3**：`wiki-lock list` 失败时 hook 永久推迟 auto-commit，没有 retry/alert surface。修：`.vault-meta/hook.log` counter，并由 `wiki lint` surfaced。
- **H4**：session 间没有 stale-lock reaper。修：SessionStart 和 `wiki lint` 调用 `wiki-lock.sh clear-stale`。

### References（5 个，同一根因）

README 中 canonical URL 修复没有 cascade 到其他文件：

- **F1**：`docs/install-guide.md` 仍写旧版本；
- **F2**：install-guide 多处把私有 repo URL 当 public canonical；
- **F3**：`docs/releases/v1.6.0.md` 三张图片指向私有 org raw URL；
- **F4**：CONTRIBUTING、AGENTS、GEMINI、ATTRIBUTION 中有私有 URL；
- **F5**：plugin / marketplace manifest 的 homepage 和 repository 指向私有 URL。

修复：全部改为 public mirror，或在非 canonical 表面明确写 private-mirror disclaimer。plugin manifest 必须使用 public canonical。

### Files（3 个）

- **W1**：`wiki/meta/` 中累积了 12 份 dated personal dev-session notes。demo vault 不应携带大量 release-prep notes。移到 `docs/audits/` 或删除，最多保留 1-2 个示例。
- **W2**：4 个 wiki 文件含 personal handle `agricidaniel`，需要确认是否是 legitimate attribution。
- **W3**：`.obsidian/workspace-visual.json` 被 tracked，属于 host-specific UI state。修：加入 `.gitignore` 并 `git rm --cached`。
